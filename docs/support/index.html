Clipboard Pro+ Support

Clipboard Pro+ helps you save, organize, and reuse copied text and links across the app, keyboard extension, and share extension.

Last updated: April 16, 2026

Getting Started

  1. Open Clipboard Pro+ and finish onboarding.
  2. In Settings, confirm clipboard tracking is enabled.
  3. Copy text while the app is active to build your History list.
  4. Pin important clips to Favorites for faster reuse.

Keyboard Extension

  1. Open iOS Settings.
  2. Go to General > Keyboard > Keyboards > Add New Keyboard.
  3. Add Clipboard Pro+ Keyboard.
  4. Enable Allow Full Access if you want the keyboard to show saved clips.
  • The keyboard can type normally without Full Access.
  • Full Access is required only for reading and updating shared saved-clip lists.
  • Free users can see up to 5 History items in the keyboard.
  • Premium unlocks additional keyboard sources such as Favorites and Recently Copied.

Share Extension

  1. Select text or open a web page in another app.
  2. Tap the system Share button.
  3. Choose Share to Clipboard Pro+.
  4. Save the shared item.
  • Free users can save the first shared item.
  • Premium unlocks full multi-item import.

Premium And Purchases

  • Premium unlocks up to 200 saved history items, Smart Collections, custom tags, iCloud sync, expanded keyboard sources, and full multi-item share import.
  • Open the main app after purchase or restore so Premium state refreshes for the extensions.
  • Use Restore Purchases from Settings if an active subscription does not appear.
  • Use Manage Subscription from Settings to review or cancel your plan.

Troubleshooting

  • If clipboard history is not updating, keep the main app open and active while copying and make sure tracking is enabled.
  • If the keyboard shows no saved clips, enable Full Access and make sure the app has at least one saved history item.
  • If shared content does not appear, open the main app once and try sharing plain text or a web URL again.
  • If purchases do not update, use Restore Purchases from Settings and then reopen the app.
