Clipboard Pro+ Support

Clipboard Pro+ helps you save, organize, and reuse copied text and links across the app, keyboard extension, and share extension.

Help Topics

  • Enable clipboard tracking in the app Settings screen.
  • Enable Clipboard Pro+ Keyboard and turn on Allow Full Access if you want keyboard access to shared clipboard lists.
  • Open the app after restoring purchases so Premium entitlements refresh for the extensions.

Troubleshooting

  • If shared content does not appear, open the main app once and try again.
  • If the keyboard shows no items, make sure Full Access is enabled and that the app has saved at least one clipboard item.
  • If purchases do not update, use Restore Purchases from the Settings screen.

Contact

Support for Clipboard Pro+ is handled through the public GitHub issue tracker.

https://github.com/mahmoudfotta/Clipboard-pro-plus/issues

Include your device model, iOS version, whether Full Access is enabled for the keyboard, and the steps to reproduce the issue.
