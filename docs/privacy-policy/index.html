Clipboard Pro+ Privacy Policy

Clipboard Pro+ stores the clipboard items you save so you can search, organize, and paste them later.

Data Handling

  • Clipboard history is stored on device by default.
  • If you enable Premium sync features, clipboard data may be stored in your private iCloud account to sync across your devices.
  • Clipboard Pro+ does not use third-party advertising SDKs or tracking code.

Extensions

  • The keyboard extension reads shared clipboard data from the app group only after the user enables Full Access in iOS Settings.
  • The share extension writes shared text and links into the app group so the main app can import them into clipboard history.

User Controls

  • You can turn clipboard tracking on or off in Settings.
  • You can clear saved history at any time.
  • You can delete or edit individual items.

Contact

For privacy questions or support requests, use the support page or open an issue on GitHub.
